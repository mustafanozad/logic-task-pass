# نظام إدارة الموظفين

نظام متكامل وشامل لإدارة الموظفين في المؤسسات التعليمية والإدارية، مع التركيز على حساب العلاوات السنوية والترفيعات الوظيفية بدقة عالية.

## الميزات الرئيسية

### 🏢 إدارة الموظفين
- إضافة موظفين جدد مع جميع البيانات الأساسية
- عرض قائمة الموظفين مع إمكانيات الفلترة المتقدمة
- ملف شخصي شامل لكل موظف مع تصميم عصري

### 📊 المحرك الذكي للحسابات
- حساب تلقائي ودقيق للعلاوات والترفيعات
- دعم مؤشرات التتبع المختلفة (4/0-4/3, 5/0-5/4)
- معالجة الأحداث المهنية المؤثرة على المسارات الوظيفية
- حساب الخدمة الفعلية مع مراعاة الإجازات الطويلة

### 📅 إدارة الأحداث المهنية
- إضافة أحداث فردية أو جماعية
- دعم جميع أنواع الأحداث: كتب الشكر، العقوبات، الإجازات، الشهادات العلمية
- تأثير تلقائي على حسابات العلاوات والترفيعات

### 🎨 واجهة مستخدم عصرية
- تصميم متجاوب يدعم جميع الأجهزة
- دعم كامل للغة العربية مع اتجاه RTL
- ألوان هادئة واحترافية مع تأثيرات بصرية جذابة
- أيقونات كبيرة وواضحة لسهولة الاستخدام

## التقنيات المستخدمة

### الواجهة الأمامية
- **React 18** - مكتبة JavaScript للواجهات
- **Material-UI (MUI)** - مكتبة مكونات واجهة المستخدم
- **Vite** - أداة بناء سريعة وحديثة
- **Axios** - للتواصل مع الخادم
- **Date-fns** - لمعالجة التواريخ

### الخادم والقاعدة de données
- **Node.js** - بيئة تشغيل JavaScript
- **Express.js** - إطار عمل للخادم
- **MongoDB** - قاعدة بيانات NoSQL
- **Mongoose** - ODM لـ MongoDB
- **Moment.js** - معالجة التواريخ في الخادم

## متطلبات التشغيل

- Node.js (الإصدار 16 أو أحدث)
- MongoDB (الإصدار 4.4 أو أحدث)
- npm أو yarn

## التثبيت والتشغيل

### 1. استنساخ المشروع
```bash
git clone <repository-url>
cd employee-management-system
```

### 2. تثبيت التبعيات
```bash
# تثبيت تبعيات الخادم
npm install

# تثبيت تبعيات العميل
cd client
npm install
cd ..
```

### 3. إعداد قاعدة البيانات
```bash
# تأكد من تشغيل MongoDB
mongod

# أو استخدم MongoDB Atlas للقاعدة السحابية
```

### 4. إعداد متغيرات البيئة
أنشئ ملف `.env` في المجلد الجذر:
```env
MONGODB_URI=mongodb://localhost:27017/employee_management
PORT=5000
```

### 5. تشغيل التطبيق
```bash
# تشغيل الخادم والعميل معاً
npm run dev

# أو تشغيلهما بشكل منفصل:
npm run server    # الخادم
npm run client    # العميل
```

### 6. الوصول للتطبيق
افتح المتصفح على: `http://localhost:5173`
