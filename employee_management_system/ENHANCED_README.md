# نظام إدارة العلاوات والترفيعات المحسّن
## Enhanced Employee Promotion and Allowance Management System

نظام متكامل وشامل لأتمتة وحوسبة العمليات المعقدة المتعلقة بحساب العلاوات السنوية والترفيعات الوظيفية لجميع الموظفين (من الكادر التدريسي والإداري) مع واجهة عصرية جميلة وأيقونات كبيرة وألوان جذابة.

## 🌟 الميزات الرئيسية

### 🏢 إدارة شاملة للموظفين
- **إضافة موظفين جدد** مع جميع البيانات الأساسية والمتغيرات المطلوبة للحسابات
- **قائمة موظفين تفاعلية** مع إمكانيات فلترة متقدمة حسب الصنف الوظيفي وتاريخ المباشرة
- **ملف موظف شامل** مع لوحة تحكم تفاعلية تعرض جميع المعلومات والمؤشرات
- **تحديث البيانات الأساسية** مع التأثير التلقائي على الحسابات

### 🧠 المحرك الذكي للحسابات
- **حساب تلقائي ودقيق** للعلاوات والترفيعات مع مراعاة جميع القواعد المعقدة
- **دعم مؤشرات التتبع المختلفة**:
  - للدرجات 10-6: نظام 4/0 إلى 4/3 (3 علاوات + ترفيع)
  - للدرجات 5-2: نظام 5/0 إلى 5/4 (4 علاوات + ترفيع)
  - للدرجة الأولى: علاوات فقط (حتى المرحلة 11)
- **معالجة الحالات الخاصة** مثل الترفيع السريع للموظفين الجدد
- **حساب دقيق للتواريخ** مع مراعاة السنوات الكبيسة وأطوال الأشهر المختلفة
- **إعادة حساب تلقائية** عند إضافة أحداث مهنية بتواريخ قديمة

### 📅 إدارة الأحداث المهنية الشاملة
- **الأحداث الإيجابية**:
  - كتب الشكر والتقدير (تقليص 1-6 أشهر)
  - الحصول على شهادة أعلى (تقليص 12 شهر - Step)
- **الأحداث السلبية**:
  - عقوبة لفت نظر (إضافة 3 أشهر)
  - عقوبة إنذار (إضافة 6 أشهر)
  - عقوبة توبيخ (إضافة 12 شهر)
- **أحداث تجميد الخدمة**:
  - إجازة بدون راتب
  - إجازة رعاية المعاقين
  - إجازة الخمس سنوات
  - إجازة أمومة
- **أحداث مخصصة** مع مرونة كاملة للتعديل اليدوي
- **تطبيق فردي أو جماعي** للأحداث مع زر "تحديد الكل"
- **قواعد تحقق وقيود** تلقائية (مثل الحد الأقصى لكتب الشكر)

### 🎨 واجهة مستخدم عصرية وجميلة
- **تصميم متجاوب** يدعم جميع الأجهزة (Desktop, Tablet, Mobile)
- **دعم كامل للغة العربية** مع اتجاه RTL
- **ألوان هادئة واحترافية** مع تأثيرات بصرية جذابة
- **أيقونات كبيرة وواضحة** من Font Awesome
- **خط Cairo العربي** الجميل والواضح
- **رسوم متحركة سلسة** وتأثيرات تفاعلية
- **بطاقات معلومات تفاعلية** مع مؤشرات ملونة

### 📊 ملف الموظف التفاعلي
- **قسم الرأس الجذاب** مع صورة الموظف والمعلومات الأساسية
- **بطاقات المؤشرات الرئيسية**:
  - الدرجة والمرحلة الحالية مع تاريخ الاستحقاق
  - الاستحقاق القادم (نوعه وتاريخه والأيام المتبقية)
  - الخدمة الفعلية (بالسنوات والأشهر والأيام)
- **نظام تبويبات أنيق**:
  - المسار الوظيفي (خط زمني للعلاوات والترفيعات)
  - سجل الأحداث المهنية (جدول تفاعلي)
  - التفاصيل الإضافية (معلومات شاملة)

### 🔧 إدارة النظام المتقدمة

- **نظام إعدادات مرن** قابل للتخصيص

- **إمكانية إعادة حساب** الاستحقاقات لموظف واحد أو جميع الموظفين

## 🎯 كيفية الاستخدام

### إضافة موظف جديد
1. انتقل إلى "الموظفين" → "إضافة موظف جديد"
2. املأ جميع البيانات المطلوبة:
   - الاسم الرباعي واللقب
   - تاريخ المباشرة بالوظيفة
   - تاريخ آخر استحقاق للعلاوة
   - مؤشر تتبع العلاوة (حسب الدرجة الوظيفية)
   - الشهادة العلمية والوظيفة
3. اختر صورة للموظف (اختياري)
4. اضغط "حفظ الموظف"

### عرض ملف الموظف
1. من قائمة الموظفين، اضغط على زر "عرض الملف"
2. ستظهر لوحة تحكم شاملة تحتوي على:
   - المؤشرات الرئيسية (الدرجة الحالية، الاستحقاق القادم، الخدمة الفعلية)
   - المسار الوظيفي (خط زمني للعلاوات والترفيعات)
   - سجل الأحداث المهنية
   - التفاصيل الإضافية

### إضافة حدث مهني
1. انتقل إلى "الأحداث المهنية" → "إضافة حدث مهني"
2. حدد الموظفين المتأثرين (فردي أو جماعي)
3. اختر نوع الحدث وتاريخه
4. املأ التفاصيل الخاصة بالحدث
5. اضغط "حفظ الحدث"

### إعادة حساب الاستحقاقات
- من ملف الموظف: اضغط "إعادة حساب الاستحقاقات"
- سيقوم النظام بإعادة حساب جميع العلاوات والترفيعات تلقائياً

## 🔧 قواعد النظام

### مؤشرات التتبع
- **الدرجات 10-6**: 3 علاوات ثم ترفيع (مؤشر 4/0 إلى 4/3)
- **الدرجات 5-2**: 4 علاوات ثم ترفيع (مؤشر 5/0 إلى 5/4)
- **الدرجة الأولى**: علاوات فقط حتى المرحلة 11

### قيود الأحداث المهنية
- **كتب الشكر**: حد أقصى 3 كتب سنوياً
- **كتب الشكر 6 أشهر**: حد أقصى 2 كتب طوال المسيرة الوظيفية
- **الترفيع السريع**: للموظفين الجدد بدرجة 8 مرحلة 5 وشهادة دبلوم

### حساب التواريخ
- **المدة الأساسية**: 12 شهر تقويمي كامل
- **دقة الحساب**: مراعاة السنوات الكبيسة وأطوال الأشهر
- **تأثير الأحداث**: تطبيق فوري على حسابات الاستحقاق

## 🎨 التخصيص

### تغيير الألوان
عدّل ملف `static/css/enhanced_style.css`:
```css
:root {
    --primary-color: #667eea;    /* اللون الأساسي */
    --secondary-color: #764ba2;  /* اللون الثانوي */
    --success-color: #28a745;    /* لون النجاح */
    /* ... المزيد من الألوان */
}
```

### إضافة أنواع أحداث جديدة
1. عدّل `EventType` في `backend/enhanced_models.py`
2. أضف المنطق في `enhanced_calculation_engine.py`
3. حدّث واجهة إضافة الأحداث

### تخصيص الإعدادات
استخدم جدول `system_settings` لإضافة إعدادات جديدة:
```python
setting = SystemSettings(
    setting_key='custom_setting',
    setting_value='value',
    setting_type='string',
    description='وصف الإعداد'
)
```
